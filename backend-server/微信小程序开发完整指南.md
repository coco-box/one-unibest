## 前期准备

### 必备条件

作为个人开发者，你需要准备以下材料：

- **个人身份证**：用于实名认证
- **个人手机号**：用于接收验证码
- **个人邮箱**：用于注册微信公众平台账号（不能被其他微信平台账号使用过）
- **个人微信号**：用于管理员身份验证
- **个人银行卡**：用于微信实名认证（姓名需与身份证一致）

### 重要说明

⚠️ **个人主体限制**：
- 个人注册的小程序**无法接入微信支付**
- 个人小程序主要盈利方式为**广告收入**
- 服务类目受限，不能选择涉及商业目的的类目
- 小程序名称不能包含商业相关词汇

## 微信小程序注册流程

### 第一步：注册微信公众平台账号

1. **访问微信公众平台**
   - 打开 [微信公众平台](https://mp.weixin.qq.com/)
   - 点击右上角「立即注册」按钮

2. **选择账号类型**
   - 选择「小程序」类型

3. **填写账号信息**
   - 邮箱：填写未被微信公众平台使用过的邮箱
   - 密码：设置登录密码
   - 确认密码：再次输入密码
   - 验证码：输入图片验证码
   - 勾选同意协议

4. **邮箱验证**
   - 登录邮箱查收验证邮件
   - 点击邮件中的确认链接

### 第二步：完善主体信息

1. **选择主体类型**
   - 选择「个人」

2. **填写个人信息**
   - 真实姓名：必须与身份证一致
   - 身份证号：输入有效身份证号码
   - 手机号：用于接收验证码
   - 验证码：输入手机收到的验证码

3. **管理员信息确认**
   - 使用个人微信扫码确认
   - 确保微信实名信息与填写信息一致

### 第三步：完善小程序信息

1. **基本信息设置**
   - 小程序名称：避免商业化词汇，建议使用「XX学习工具」、「XX测试工具」等
   - 小程序头像：上传符合规范的头像
   - 小程序介绍：简要描述小程序功能
   - 服务类目：选择「工具-学习教育」等个人适用类目

2. **获取 AppID**
   - 在「开发」-「开发管理」-「开发设置」中查看
   - AppID 是小程序的唯一标识，开发时需要用到

### 第四步：小程序备案（必须）

根据工信部要求，所有小程序都需要进行备案：

1. **准备备案材料**
   - 个人身份证正反面照片
   - 个人手机号（与注册时一致）
   - 居住地址证明（如与身份证地址不同，需提供居住证或社保证明）

2. **填写备案信息**
   - 在微信公众平台「设置」-「基本设置」-「小程序备案」中提交
   - 填写小程序基础信息和主体信息
   - 上传相关证明材料

3. **等待审核**
   - 平台初审：1-3 个工作日
   - 工信部审核：7-20 个工作日
   - 审核通过后会收到工信部短信通知

4. **短信核验**
   - 收到工信部短信后，访问 [备案信息管理系统](https://beian.miit.gov.cn/)
   - 完成短信核验流程

## 微信一键登录功能实现

### 登录流程说明

微信小程序登录采用以下流程：

1. **前端调用 `wx.login()`** 获取临时登录凭证 `code`
2. **前端将 `code` 发送到后端**
3. **后端调用微信 `code2Session` 接口** 换取 `openid` 和 `session_key`
4. **后端生成自定义登录态**（JWT Token）
5. **返回 Token 给前端**，前端存储用于后续请求

### 后端实现

**微信配置 `src/config/wechat.ts`**：

```typescript

  appSecret: process.env.WECHAT_APP_SECRET!,

};
```

```typescript
import axios from 'axios';
import { wechatConfig } from '../config/wechat.js';

export interface Code2SessionResponse {
  openid?: string;
  session_key?: string;
  unionid?: string;
  errcode?: number;
  errmsg?: string;
}

export class WechatService {
  /**
   * 通过 code 换取 openid 和 session_key
   */
  static async code2Session(code: string): Promise<Code2SessionResponse> {
    try {
      const response = await axios.get(wechatConfig.code2SessionUrl, {
        params: {
          appid: wechatConfig.appId,
          secret: wechatConfig.appSecret,
          js_code: code,
          grant_type: 'authorization_code',
        },
      });

      return response.data;
    } catch (error) {
      console.error('微信 code2Session 请求失败:', error);
      throw new Error('微信登录服务异常');
    }
  }

    return true;
  }
}
```

**用户模型 `src/models/user.ts`**：

```typescript
export interface User {
  id: string;
  openid: string;
  unionid?: string;
  nickname?: string;
  avatar?: string;
  sessionKey: string;
  createdAt: Date;
  updatedAt: Date;
}

// 简单的内存存储（生产环境建议使用数据库）
const users: Map<string, User> = new Map();

export class UserModel {
  static async findByOpenid(openid: string): Promise<User | null> {
    return users.get(openid) || null;
  }

  static async create(userData: Omit<User, 'id' | 'createdAt' | 'updatedAt'>): Promise<User> {
    const user: User = {
      id: Date.now().toString(),
      ...userData,
      createdAt: new Date(),
      updatedAt: new Date(),
    };
    
    users.set(user.openid, user);
    return user;
  }

  static async update(openid: string, updateData: Partial<User>): Promise<User | null> {
    const user = users.get(openid);
    if (!user) return null;

    const updatedUser = {
      ...user,
      ...updateData,
      updatedAt: new Date(),
    };

    users.set(openid, updatedUser);
    return updatedUser;
  }
}
```

**JWT 工具 `src/utils/jwt.ts`**：

```typescript
import jwt from 'jsonwebtoken';

const JWT_SECRET = process.env.JWT_SECRET!;
const JWT_EXPIRES_IN = process.env.JWT_EXPIRES_IN || '7d';

export interface JwtPayload {
  userId: string;
  openid: string;
}

export class JwtUtils {
  static sign(payload: JwtPayload): string {
    return jwt.sign(payload, JWT_SECRET, { expiresIn: JWT_EXPIRES_IN });
  }

  static verify(token: string): JwtPayload {
    return jwt.verify(token, JWT_SECRET) as JwtPayload;
  }
}
```

**认证控制器 `src/controllers/auth.ts`**：

```typescript
import { Request, Response } from 'express';
import { WechatService } from '../services/wechat.js';
import { UserModel } from '../models/user.js';
import { JwtUtils } from '../utils/jwt.js';
import { ApiResponse } from '../utils/response.js';

export class AuthController {
  /**
   * 微信小程序登录
   */
  static async wxLogin(req: Request, res: Response) {
    try {
      const { code } = req.body;

      if (!code) {
        return ApiResponse.error(res, '缺少登录凭证', 400);
      }

      // 1. 调用微信接口换取 openid 和 session_key
      const wxResult = await WechatService.code2Session(code);

      if (wxResult.errcode || !wxResult.openid) {
        return ApiResponse.error(res, wxResult.errmsg || '微信登录失败', 400);
      }

      // 2. 查找或创建用户
      let user = await UserModel.findByOpenid(wxResult.openid);
      
      if (!user) {
        // 首次登录，创建用户
        user = await UserModel.create({
          openid: wxResult.openid,
          unionid: wxResult.unionid,
          sessionKey: wxResult.session_key!,
        });
      } else {
        // 更新 session_key
        user = await UserModel.update(wxResult.openid, {
          sessionKey: wxResult.session_key!,
        });
      }

      // 3. 生成 JWT Token
      const token = JwtUtils.sign({
        userId: user!.id,
        openid: user!.openid,
      });

      // 4. 返回登录结果
      return ApiResponse.success(res, {
        token,
        user: {
          id: user!.id,
          openid: user!.openid,
          nickname: user!.nickname,
          avatar: user!.avatar,
        },
      }, '登录成功');

    } catch (error) {
      console.error('微信登录错误:', error);
      return ApiResponse.error(res, '登录失败，请稍后重试', 500);
    }
  }
}
```

```typescript
export interface ApiResponseData<T = any> {
  code: number;
  message: string;
  data?: T;
  timestamp: string;
}

export class ApiResponse {
  static success<T>(res: Response, data?: T, message = '操作成功'): Response {
    return res.json({
      code: 200,
      message,
      data,
      timestamp: new Date().toISOString(),
    });
  }

  static error(res: Response, message = '操作失败', code = 500): Response {

      message,
      timestamp: new Date().toISOString(),
    });
  }
```

**认证中间件 `src/middleware/auth.ts`**：

```typescript
import { Request, Response, NextFunction } from 'express';
import { JwtUtils } from '../utils/jwt.js';
import { ApiResponse } from '../utils/response.js';

export interface AuthRequest extends Request {
  user?: {
    userId: string;
    openid: string;
  };
}

export const authMiddleware = (req: AuthRequest, res: Response, next: NextFunction) => {
  try {
    const authHeader = req.headers.authorization;
    
    if (!authHeader || !authHeader.startsWith('Bearer ')) {
      return ApiResponse.error(res, '未提供认证令牌', 401);
    }

    const token = authHeader.substring(7);
    const payload = JwtUtils.verify(token);
    
    req.user = payload;
    next();
  } catch (error) {
    return ApiResponse.error(res, '认证令牌无效', 401);
  }
};
```

### 前端实现（基于你的 unibest 项目）

**更新 `src/store/token.ts`**：

```typescript
// 在现有的 getWxCode 函数后添加登录逻辑
export const wxLogin = async () => {
  try {
    // 1. 获取微信登录凭证
    const code = await getWxCode();
    
    // 2. 调用后端登录接口
    const response = await uni.request({
      url: 'http://localhost:3000/api/auth/wx-login',
      method: 'POST',
      data: { code },
    });

    if (response.data.code === 200) {
      // 3. 存储 token
      const { token, user } = response.data.data;
      uni.setStorageSync('token', token);
      uni.setStorageSync('userInfo', user);
      
      return { success: true, data: response.data.data };
    } else {
      throw new Error(response.data.message);
    }
  } catch (error) {
    console.error('微信登录失败:', error);
    return { success: false, error: error.message };
  }
};
```

   - 填写审核信息和测试账号

3. **发布上线**
   - 审核通过后点击「发布」
   - 小程序正式上线

## 常见问题与解决方案

### 1. 个人主体限制问题

**问题**：个人小程序无法使用支付功能
**解决方案**：
- 专注于广告变现模式
- 考虑升级为企业主体（需要营业执照）
- 使用第三方支付解决方案（需谨慎合规）

### 2. 备案审核被拒

**问题**：小程序名称或类目不符合个人主体要求
**解决方案**：
- 避免商业化词汇，使用「学习」、「工具」、「测试」等词汇
- 选择「工具-学习教育」等个人适用类目
- 详细描述小程序的学习或工具属性

### 3. code2Session 调用失败

**问题**：后端调用微信接口返回错误
**解决方案**：
- 检查 AppID 和 AppSecret 是否正确
- 确认 code 是否已过期（5分钟有效期）
- 检查网络连接和防火墙设置

### 4. JWT Token 验证失败

**问题**：前端请求时认证失败
**解决方案**：
- 检查 token 是否正确存储和传递
- 确认 JWT_SECRET 配置是否一致
- 检查 token 是否已过期

### 5. 跨域问题

**问题**：前端请求后端接口时出现跨域错误
**解决方案**：
- 确保后端已配置 CORS 中间件
- 在小程序后台配置服务器域名
- 开发环境可以使用代理或关闭域名校验
